### C2 [中] log 槽 Mutex 在磁碟寫入期間被握著，`state_with` 又在分頁清單鎖內鎖它 → 慢磁碟／防毒卡住時整個 UI 凍結

## D. Rust 設定／沙盒／雜項

### D1 [高] `sandbox_clear` 在 Windows 必定失敗，且留下「已被 git 除名但目錄仍在」的殘骸
